# SVGEO

*Can you name the location from its shape?*

[Play Now](https://svgeo.vercel.app/)

## Game Categories

* Countries
* Canada Provinces
* US States
* India States
* DMAs 
* India Districts

## Modes

* **Easy**: Pick the correct location from 3 options.
* **Medium**: Type in the correct location.
* **Hard**: Type in the correct location and the location is rotated.
